# 询盘助手 · Inquiry Assistant

把获准的客户聊天与企业资料整理成销售回复建议的本地工作台。业务员可以手动更新聊天、选择客户、生成回复、按要求调整或润色自己的话，检查后复制到 WhatsApp 发送。

当前版本 **0.7.0a1 / Alpha**，适合一家公司、一台电脑的受控试点。源码运行于 macOS / Linux；工作区锁依赖 POSIX，暂不支持 Windows 原生运行。当前成品安装套件面向 Apple 芯片 Mac，要求 macOS 14 或以上，首次由实施人员协助安装。

**业务员下载安装包：** [Mac 下载页](https://github.com/zhengshuyuan2023uk/inquiry-assistant-downloads/releases) · [现场安装手册](docs/MAC_ONSITE.md)。下载页中的 `inquiry-assistant-…-macos-arm64-….zip` 是现场安装套件；本仓库面向阅读、修改和构建源码的开发者。

## 已有功能

- **客户与聊天**：反复扫描已连接 WhatsApp 来源、搜索勾选、暂停或恢复同步；手动导入已选会话并去重。客户名称跟随 WhatsApp，不设另一套本地备注。
- **三种回复操作**：AI 生成回复、按本次要求调整、润色业务员原文。对客正文使用客户语言，理由和提醒使用中文；支持生成预览与停止。
- **企业资料与回复设置**：资料页用表单新增、编辑、移除资料并设置有效期；回复设置集中维护“怎么说”“需要问什么”“哪些情况先确认”，统一保存。知识历史和旧回复的引用依据保留，CLI 支持版本回滚。
- **人工审核与复盘记录**：保存草稿、采用版本、资料依据和运行状态。复制或批准只记录待人工发送，程序不发送消息。
- **独立工作区**：每家公司使用自己的 SQLite 数据库与知识目录；区分合成演练和客户模式，支持工作区备份、恢复及 JSON / JSONL 导入。
- **文件适配**：支持明确账号和收件箱范围的 Chatwoot 文本事件文件转换；不是在线 Webhook 集成。

## 先运行合成演示

需要 Python 3.10+，包含标准库 `sqlite3`。演示无需 pip、Docker、Node、WhatsApp 登录或 AI 账号。

```sh
git clone https://github.com/zhengshuyuan2023uk/inquiry-assistant.git
cd inquiry-assistant
python3 -B create_workbench_demo.py --workspace workspaces/demo
python3 -B start_workbench.py --workspace workspaces/demo --port 0 --open
```

程序只监听 `127.0.0.1`，`--port 0` 自动选择空闲端口并在终端打印地址；`--open` 打开浏览器。保持终端运行，按 Ctrl+C 停止。演示创建命令只接受新路径或空目录，已有演示可直接运行最后一条命令。

初始演示有 5 个虚构客户、15 条合成消息和 4 份固定示例草稿。可以查看客户、企业资料和回复设置，也可体验合成来源的“更新聊天”。这些草稿不是模型生成结果。**点击 AI 生成、调整或润色会调用真正的模型**，需要完成下一节的配置。

界面说明对应当前源码。已发布的安装套件可能使用较早界面，现场安装请以所下载套件附带的手册为准。

## 需要生成回复时

网页默认通过本机 **Codex App Server** 调用云端模型，后台进程按需启动并复用。每次生成使用独立临时会话，聊天与知识由本产品的工作区管理，不依赖 Codex 桌面窗口。当前没有独立的第三方模型 API 运行器。

在运行产品的同一系统用户下准备已授权的 Codex 后台程序，确保 `codex` 在 `PATH` 中。当前适配基于 Codex 0.145.0，并需要文件形式的登录凭据；仅钥匙串登录尚未适配。安装套件会为客户建立独立登录目录。开发配置、认证边界与排查入口见[开发说明](docs/DEVELOPMENT.md)。

“更多 → 负责人设置”可选择账号实际可用的模型。回复消耗所配置账号的额度，模型计算发生在云端；企业与客户资料须在获准范围内处理。预览完成后仍需人工检查金额、单位、事实和语气，再复制发送。

## 连接真实 WhatsApp

首次由实施人员建立空的客户工作区、绑定客户自己的 WhatsApp 桥接，然后业务员反复扫描勾选和手动更新。Mac 安装套件提供编号操作入口，详见[现场安装手册](docs/MAC_ONSITE.md)。开发者可用 `python3 -B configure_whatsapp.py --help` 查看只读来源的配置参数。

桥接后台接收同步缓存，“更新聊天”导入的是桥接已收到的选中会话，不保证手机完整历史。桥接缓存可能包含该账号的其他会话，工作台选中范围与桥接缓存范围不同。名称也取决于桥接收到的联系人信息。

## 当前边界

当前没有员工登录、团队权限、共享 SaaS、自动发送、定时导入、附件识别、自动训练或自动提炼销售 Skill。“负责人设置”只是界面分组。服务仅供本机使用，不应直接暴露到公网或局域网。

本地健康检查和离线测试不能代替客户实机、账号、网络、聊天覆盖和回复质量验收。升级前先备份，再在独立恢复副本验证；现场安装入口不是自动升级程序。
