# 询盘助手：M4 Mac 现场安装手册

适用：实施人员到客户现场，为一名业务员安装在客户自己的 Apple 芯片 Mac 上。套件要求 macOS 14 或以上，安装前自动检查；客户机的实际 macOS 版本仍需现场确认。本手册对应询盘助手 0.7.0a1 Mac 套件 r3，包含企业资料表单、三部分回复设置及自有 MIT 许可与来源说明。[r3 下载页](https://github.com/zhengshuyuan2023uk/inquiry-assistant-downloads/releases/tag/macos-arm64-0.7.0a1-r3)。

这是由实施人员操作的试用部署套件，包含后台程序，不是已经完成客户生产验收的 App Store 应用。业务员日常只打开桌面“打开询盘助手”。

## 出发前准备

- 将构建好的完整 `inquiry-assistant-0.7.0a1-macos-arm64-r3.zip` 和本手册带到现场，可用 U 盘或 AirDrop。不要复制开发电脑的整个项目目录、聊天库、`auth.json` 或 WhatsApp 登录文件。
- 客户的 Mac 登录密码（由客户本人输入；首次安装 Python 可能需要管理员权限）。
- 可正常使用的网络、客户的 WhatsApp 手机、可使用 Codex 的客户自己的 AI 账号。AI 登录使用客户本人的浏览器，不需要客户学习 Codex，也不需要提供密码给我们。
- 企业名称、主营业务、产品或服务说明、有效报价与适用条件、不能承诺的事项。资料不齐可以先装好，但先不把缺资料生成的建议用于报价。

套件包含：询盘助手、Codex 0.145.0 的 Apple 芯片后台程序、只供采集的 WhatsApp 连接程序、Python 3.13.15 官方安装包、对应来源与许可说明。安装软件阶段不需要现场下载 Go、Node、Docker 或 MCP 插件。登录和聊天连接仍需联网。

## 现场按顺序操作

### 1. 解压并安装

在客户日常使用的 macOS 用户下解压 ZIP，打开 `01-现场安装.command`。不要使用 root 或把本套件装进我们的账号。

如果没有合适的 Python，入口会提示安装套件 `runtime/python-macos.pkg`；按官方安装器完成后，再打开现场安装入口。已有可用 Python 3.10+ 时可复用，安装工具会记录解释器的绝对路径。

按提示填写客户真实企业名称和行业。程序创建全新的空白客户工作区，不带虚构客户、询盘或示例报价。虚构演示是同一程序的可选独立工作区，按[源码说明](https://github.com/zhengshuyuan2023uk/inquiry-assistant#先运行合成演示)另行创建；现场编号入口始终打开正式客户工作区。重复安装不会覆盖已有聊天、企业知识或客户选择，也不作为版本升级操作。

macOS 如提示确认运行下载的软件，请客户按系统提示确认当前套件和后台文件；本套件未做 Apple 开发者签名、公证，不要全局关闭系统安全检查。

### 2. 连接 AI

打开 `02-连接AI.command`，请客户在弹出的浏览器完成自己的 ChatGPT/Codex 登录。后台登录信息保留在这台 Mac 的专用目录中，不导出给我们。账号必须具有可用额度和可用模型。

当前产品通过 Codex App Server 使用客户授权。Codex 官方同时支持 ChatGPT 登录和 API Key，但这份现场流程采用已经验证过的 ChatGPT 登录路径，不需要先购买 API 额度。[官方认证说明](https://learn.chatgpt.com/docs/auth)

### 3. 连接 WhatsApp

打开 `03-连接WhatsApp.command`。首次登录时显示二维码，客户在手机 WhatsApp 的“已关联设备 → 关联设备”中扫描。二维码会更新、过期；如果等待时间过长，重新打开连接入口获取当前状态和新二维码。

扫码后等连接建立。这个连接程序在后台接收消息，工作台的“更新聊天”将其已收到的选中会话导入客户数据库；它不能保证手机所有历史记录都已到齐。日常有效登录通常不必重新扫码。

桥接的本地缓存可能包含该账号同步来的其他会话；工作台只导入业务员明确勾选的会话。这两个数据范围不同，首次接入应使用客户授权的业务账号。

### 4. 打开正式工作台并选择客户

打开 `04-打开工作台.command`，或新建立的桌面“打开询盘助手”。确认页面显示客户刚填写的企业名称，而不是演练企业。

在“添加 / 管理客户”中扫描并勾选首批试用客户，保存后点击“更新聊天”。新发现的客户不会自动勾选；名称在 WhatsApp 中维护。

桌面入口会启动所需后台并打开正式工作区。关闭启动窗口后后台继续运行；重启电脑后再双击桌面入口。当前不设置开机自启，Mac 关机、休眠或网络不通时不能承诺持续接收。

### 5. 加入真实企业资料

在导航的“企业资料”中点击“新增资料”，可用表单新增、编辑、移除资料及设置有效期。先由实施人员与客户核对适用范围、来源和有效期，再保存；历史版本及旧回复引用仍保留。空工作区没有模拟报价；批量 JSON 配置由实施人员通过“更多 → 负责人设置 → 高级资料维护”或 CLI 发布。

在“回复设置”的“怎么说”填写沟通习惯，在“需要问什么”勾选必问信息或添加自定义问题，在“哪些情况先确认”填写需人工确认的业务事项，最后点击“保存回复设置”统一保存。先确认事实，再设定表达偏好。没有依据的价格、时效和履约条件交给人工确认；资料或设置更新后，已有回复需重新核查。

### 6. 验收后交给业务员

打开 `05-检查安装.command` 检查本地安装状态。它不会调用模型、发送消息，也不以文件存在代替 WhatsApp 已登录或 AI 可正常生成。

以下项目必须现场实际完成，检查命令不能替代：

- [ ] 显示正确企业；没有我们的测试聊天、测试联系人或虚构报价。
- [ ] 在“企业资料”保存一份客户核对过的资料和有效期；“回复设置”三部分保存后重新打开仍正确。
- [ ] 客户使用自己的 AI 账号；“更多 → 负责人设置”可读取可用模型。Luna 不可用时，由负责人明确选择其他可用型号。
- [ ] WhatsApp 显示已连接；由客户用自己的测试联系人产生一条新消息，点击更新后能看到正确记录。
- [ ] 再次更新不重复新增同一条消息；新增客户可以再次扫描并勾选。
- [ ] 客户同意云端处理范围后，用一条获准的询盘验证生成、个性化调整、润色和复制。检查语言、金额、单位、理由和企业资料依据。
- [ ] 关闭启动窗口、重新打开桌面入口，仍是同一家企业；重启 Mac 后重新打开，连接和聊天更新可恢复。
- [ ] 完成一份工作区备份，恢复到新目录进行核对。确认恢复后需要重新绑定 WhatsApp 来源。
- [ ] 业务员能独立完成“打开 → 更新 → 选客户 → 生成 → 检查修改 → 复制”。发送仍由本人在 WhatsApp 完成。

## 数据与维护

默认安装位置：当前客户用户的 `~/Library/Application Support/InquiryAssistant/`。Finder 使用“前往 → 前往文件夹”可打开。不要将整个目录发回给我们排错。

| 位置 | 用途 |
| --- | --- |
| `app/`、`bin/`、`deploy/` | 软件和启动组件 |
| `workspace/` | 客户已导入的聊天、企业知识、回复和采用记录 |
| `codex-home/` | 客户 AI 登录，按密码保护，禁止打包分享 |
| `bridge_run/store/` | WhatsApp 登录与桥接接收到的聊天缓存 |
| `logs/` | 运行诊断；可能含连接元数据和登录二维码，需按客户资料保护 |

不删除登录目录来“修复连接”，不覆盖已有安装。先保留数据和诊断，再联系实施负责人。当前没有自动升级；软件升级前做工作区备份并在独立恢复副本验证，再由实施人员执行，不能直接用新套件重复安装冒充升级。

现场负责人可在安装目录的 `app` 文件夹运行下列命令；`$HOME` 是客户当前用户的标准主目录变量，不要改写它：

```sh
python3 -B -m inquiry_product \
  --workspace "$HOME/Library/Application Support/InquiryAssistant/workspace" \
  backup --output "$HOME/Desktop/询盘助手-首次验收备份.zip"
```

备份包含客户已导入的数据，按客户约定保存；不包含 AI 登录、WhatsApp 登录和来源连接配置。先验证备份能够恢复，再讨论清理旧文件。

现场验收记录建议：企业、使用人、Mac/macOS、安装日期、软件版本、选中会话数量、实际历史覆盖、测试结果、备份位置、未解决问题、维护联系人。不要在验收表中记录密码、密钥或聊天正文。

## 常见情况

- **安装提示已有目录**：不要删除重装。已有客户数据时应先检查现有安装；升级另走备份与验证流程。
- **页面只有空白客户列表**：先确认 WhatsApp 已连接且收到会话，再打开管理客户扫描，保存选择并更新。
- **工作台可打开，但没有新消息**：检查连接入口显示的实际连接状态；工作台打开不代表 WhatsApp 一直在线。
- **AI 登录成功但无法生成**：核对账号额度、网络和可用模型；“有登录文件”不代表模型调用验收通过。
- **系统限制文件凭据**：当前适配依赖文件凭据。企业如强制仅钥匙串，应暂停 AI 接入并由负责人调整方案，不绕过企业策略。
- **客户提出自动发送或多人共用**：当前安装套件不包括这两项；记录需求后另行评估。

## 保留与清理

保留客户安装目录、客户授权的备份、验收记录。原始 ZIP 建议留一份以便复现版本。

验收后可以提议清理“下载”中的解压副本和重复 ZIP；必须由客户确认准确路径后再删除。它们不是运行数据目录；删除安装目录则可能同时删除聊天和登录，不能混为一谈。
