# 询盘助手 · Mac 企业试用版

版本：0.7.0a1 / Mac 套件 r3，供 Apple 芯片 Mac 受控试点。

帮助业务员查看获准的 WhatsApp 询盘，结合企业资料生成、调整和润色回复。业务员检查后在 WhatsApp 中手动发送。

首次安装由实施人员协助。在安装套件根目录依次运行：

1. `01-现场安装.command`
2. `02-连接AI.command`，客户使用自己的账号登录。
3. `03-连接WhatsApp.command`，客户使用手机扫码。
4. `04-打开工作台.command`，选择客户、更新聊天、补充企业资料。
5. `05-检查安装.command`，再实际验证新消息、回复和重启。

已经安装后，日常双击桌面的“打开询盘助手”。“企业资料”支持表单新增、编辑、移除和设置有效期；“回复设置”分为“怎么说”“需要问什么”“哪些情况先确认”，检查后统一保存。客户名称在 WhatsApp 中维护。

正式安装创建空白客户工作区，不带虚构客户、聊天或报价。需要体验虚构演示时，由实施人员按[源码说明](https://github.com/zhengshuyuan2023uk/inquiry-assistant#先运行合成演示)另建工作区；演示和正式使用是同一套程序，数据分别保存。

- [完整现场安装手册](docs/MAC_ONSITE.md)
- [组件来源与版本](docs/MAC_COMPONENTS.md)

套件适用于 Apple 芯片 Mac（含 M4），要求 macOS 14 或以上。安装包包含后台组件及 Python 安装器；账号授权、聊天连接和 AI 生成需要网络。没有附带开发者账号、客户聊天或企业报价。

当前为单机试用部署，未提供 Windows 原生支持、多人权限、自动发送和自动升级。安装后的数据保存在客户自己的电脑；升级前由实施人员备份并在恢复副本验证，重复安装不会完成升级。需要备份和维护时联系实施负责人。
